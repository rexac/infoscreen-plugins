# Phone device integration

The Phone sources previously carried in e5-linux `devices/t551m/infoscreen/phone` are maintained here at `plugins/phone`. Imported from e5-linux commit `b7282af`; original history and authorship remain there. Shared transport, incoming call UI, SIM labels, HFP routing and sound settings require the integrated infoscreen core and common OpenWrt backend. The release version is unchanged by this source migration.
